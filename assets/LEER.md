# Assets requeridos

Antes de correr la app, necesitás generar los siguientes archivos de imagen:

1. `icon.png` — 1024x1024px — ícono de la app
2. `splash.png` — 1284x2778px — pantalla de splash (fondo #FAF8F5)
3. `adaptive-icon.png` — 1024x1024px — ícono adaptativo para Android
4. `notification-icon.png` — 96x96px — ícono de notificación (solo Android, fondo transparente)

## Cómo crearlos rápido

Podés usar cualquier editor de imágenes. El emoji del hogar (🏡) sobre fondo #FAF8F5 funciona perfecto.

Opción rápida: usá https://www.appicon.co/ para generar todos los tamaños desde una imagen PNG.

Para pruebas iniciales, podés copiar cualquier PNG y renombrarlo — la app arrancará igual.
